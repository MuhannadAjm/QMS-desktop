## Summary

Phase 11X created a standalone Windows desktop application for managing QMS Desktop licenses. The app wraps the existing `license-admin/` React/Vite UI in a Tauri 2 (Rust + WebView2) window. It connects to Supabase over the internet for all license operations. No localhost, no browser, and no developer tooling is required after installation.

### How admin security works

The `GenerateLicense.tsx` page calls:
```typescript
const { data: { session } } = await supabase.auth.getSession();
const jwt = session?.access_token;
fetch(url, { headers: { Authorization: `Bearer ${jwt}` } })
```

The Edge Function server-side does:
1. Extracts JWT from `Authorization: Bearer <jwt>` header
2. Calls `supabase.auth.getUser(jwt)` using the service role client (server-side only)
3. Looks up the user in `license_admin_profiles`
4. Returns 403 if not found

The service role key never leaves Supabase's servers.

## Architecture Chosen

**Option 1 — Tauri wrapper inside `license-admin/`**

Added `src-tauri/` as a subdirectory of the existing `license-admin/` folder. The existing React UI in `src/` was not modified. The Tauri Rust backend is minimal (no custom commands — all Supabase calls go through the WebView JavaScript).

```
license-admin/
  src/                      ← Existing React UI (unchanged)
  src-tauri/
    Cargo.toml              ← Minimal: only tauri = "2"
    src/main.rs             ← No console window in release
    src/lib.rs              ← tauri::Builder::default().run()
    build.rs                ← tauri_build::build()
    tauri.conf.json         ← App name, bundle ID, CSP, icons
    capabilities/
      default.json          ← core:default only
    icons/                  ← Generated by tauri icon command
  package.json              ← Updated: added @tauri-apps/cli, tauri script
  vite.config.ts            ← Dev port 1421, Tauri-friendly build target
  .env.example              ← VITE_SUPABASE_URL + VITE_SUPABASE_ANON_KEY
  .env.local                ← NOT committed; populated before building
  .gitignore                ← node_modules, dist, src-tauri/target, .env.local
  README_DESKTOP.md         ← Build, install, security, architecture docs
```

**Why Option 1:**
- Reuses existing React code with zero changes
- Single source of truth for the admin UI
- No code duplication between `license-admin/` and a separate `license-admin-desktop/`
- Simpler maintenance: UI changes in `src/` are automatically picked up by the Tauri build

## Required Environment Variables

Before building, create `license-admin/.env.local`:

```
VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

These are embedded at build time by Vite into the bundled JavaScript. They are safe to embed (public anon key, restricted by RLS; Supabase URL is public). They are NOT secrets.

## How to Install on Another Device

1. Copy `QMS-License-Admin-1.0.0-test.msi` to the target Windows machine.
2. Double-click to run the installer.
3. Open **QMS License Admin** from the Start menu.
4. Log in with an account that has a row in `license_admin_profiles`.
5. Internet is required for login and all license operations.

---

## How to Add Admin Users

1. Create a user in Supabase Dashboard → Authentication → Users.
2. Insert a row in `license_admin_profiles`:
   ```sql
   INSERT INTO license_admin_profiles (id, role)
   VALUES ('<user-uuid-from-supabase>', 'admin');
   ```
3. Roles: `admin` (full access) or `viewer` (read-only, depending on UI enforcement).

## Known Issues

1. **Offline login not possible** — Supabase auth requires internet. Existing sessions (from `localStorage`) persist offline but cannot be refreshed. This is expected behavior for a cloud-connected tool.
2. **Icon is a simple "LA" teal placeholder** — Replace `src-tauri/source-icon.png` with a final branded 512×512 PNG and re-run `npx tauri icon src-tauri/source-icon.png` to regenerate.
3. **No EULA in installer** — Not included (internal tool, not distributed externally). Can be added to `tauri.conf.json` `bundle.licenseFile` if needed.
